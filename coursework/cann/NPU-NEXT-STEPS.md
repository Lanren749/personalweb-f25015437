## 再实现并验证

1. 先不追求性能：按官方工程定义的参数和属性实现一个正确的基线，
   对照 `dense_reference()` 的数学语义。
2. 在 host / tiling 层确认 B、M、N、K，处理两种输入类型与四种布局；
   保证输入不被修改，输出 shape 为 `[B]`，类型为 FP32。
3. 在 kernel 中先完成 K 维点积，再对完整 N 维求最大值，最后沿 M 维求和；
   未覆盖完 N 时不能提前把局部最大值相加。
4. 每块按有效长度处理尾部，最大值初始设为负无穷或第一个真实元素，
   补齐区域不能让负相似度被 0 覆盖。
5. 用官方允许的接口实现 Cube 矩阵乘、Vector 归约与数据搬运；
   所有 API 和同步要求均以本机所装版本对应的官方文档为准。
6. 在 NPU 上跑官方全部精度用例，保存原始输出与失败记录；
   再使用题目要求的 `msprof` 采集性能。工具参数须根据实际安装版本核对。
7. 只有取得真实评测日志，才能写“评测通过”和性能数据。当前项目不具备该证据。
