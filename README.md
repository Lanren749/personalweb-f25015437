## 快速运行

网站没有构建步骤和第三方前端依赖。下载仓库后直接打开 `index.html`，或运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8000`。桌面与手机均可使用，禁用 JavaScript 时正文仍可见。

CANN 示例的运行、测试与硬件限制请见 [作业/CANN算子预研作业/README.md](作业/CANN算子预研作业/README.md)。扫描报告的工具版本、原始输出与复现步骤请见 [作业/许可证测试作业](作业/许可证测试作业/)。

项目源码和当前完成状态请见 [项目/README.md](项目/README.md)。项目副本已清理本机签名、密钥、数据库、日志和开发者工具私有配置，运行时请按各项目 README 配置自己的环境。
