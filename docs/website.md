# 个人网站运行与检查

## 运行

本网站只有 `index.html` 和本地照片 `photo.jpg`，无需 npm 安装或云服务。

```sh
git clone https://github.com/Lanren749/personalweb-f25015437.git
cd personalweb-f25015437
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000`；结束预览时在终端按 Ctrl+C。也可直接双击 HTML 文件。

## 检查方法

- 桌面与手机宽度下，导航可用、文字不溢出、照片加载正常。
- 点击“课程作业”可跳转到四张任务卡片，卡片链接指向本仓库相应目录。
- 禁用 JavaScript 仍能看到全部内容；页面的渐入动画只是增强功能。
- 使用 Tab 键能看到链接的焦点边框；设置“减少动态效果”后关闭渐入与平滑滚动。
- 站点不加载 CDN、第三方统计、远程字体或 npm 依赖。

## 可选：GitHub Pages

网站源码上传与 GitHub Pages 上线是两个独立状态。若希望获得在线网页，可在仓库 Settings → Pages 中选择从 `main` 分支根目录发布。启用与构建成功后，使用 GitHub 提供的实际地址核对页面；不要仅凭预期地址宣称部署成功。
