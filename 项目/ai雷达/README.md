# 东浩兰生智投 AI 战略投资雷达

宋佳威 · 上海杉达学院 · F2505437 · F250117

这是我在东浩兰生公司 AI 竞赛中担任助教时完成的项目源码。项目面向投资研究场景，把产业方向、企业线索、公开来源、协同潜力和人工复核组织成一个网页工作台。

## 项目内容

- Node.js + Express 后端，提供登录、权限、产业方向、企业档案、信号、周报和研究接口。
- Vue 网页工作台，展示产业方向、候选企业、研究报告和人工复核入口。
- MySQL 数据模型，保存方向、能力、投资边界、信号、企业、评分、报告和复核记录。
- 公开信息采集和研究流水线，支持来源解析、去重、国内候选过滤、证据记录和 AI 研究草稿。
- 测试覆盖调度、配置校验、来源解析、研究流水线和复核接口。

## 我的完成内容

我在竞赛中担任助教并参与完成这一系统。公开目录保留当前的网页端、服务端、数据模型和测试代码，方便查看项目实际结构和可复现部分。

## 本地运行

先安装 Node.js 依赖，并准备一个专用的空 MySQL 数据库：

```sh
cp .env.example .env
npm ci
npm test
```

在 `.env` 中填写 `DB_HOST`、`DB_USER`、`DB_PASS`、`DB_NAME=radar_demo`、至少 32 位 `JWT_SECRET`，以及两个不同且至少 12 位的演示密码：`DEMO_ADMIN_PASSWORD`、`DEMO_INVESTOR_PASSWORD`。初始化演示数据时运行：

```sh
npm run setup
npm start
```

打开 `http://127.0.0.1:3211/`。AI 研究能力需要用户自行配置 `AI_KEY`；仓库不包含任何密钥。`npm run setup` 会重建专用演示库中的表和演示数据，不要对生产数据库运行。

本次只运行不连接 MySQL 的服务单元测试和公开信息流水线测试：36 项服务测试及流水线用例通过。Web 工作台需要 MySQL 才能完整启动和登录，GitHub 源码状态不代表线上部署或竞赛评审结论。
