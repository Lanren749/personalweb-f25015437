## 复现提醒

- 项目源码不包含 API Key、数据库、签名文件、本机日志或开发者工具私有配置。
- `hongmeng` 的 HarmonyOS 构建需要 DevEco Studio；网页版可以按项目 README 安装依赖后运行测试。

- `记账` 使用 `YOUR_WECHAT_APPID` 和 `YOUR_CLOUD_ENV_ID` 占位符，导入微信开发者工具后再配置自己的小程序与云环境。
- 三个目录都保留 README 和源码入口，老师可以先看项目说明，再按环境要求复现。
