# 比赛雷达 · 网页版

这是一套独立的网页与 Node 服务，复用原生 App 中的国内筛选、官方来源解析和 AI 证据校验逻辑。原 ArkTS App 及签名配置没有被替换。网页不自动同步原生 App 本机已有收藏与笔记。网页账号是多用户账号，每个账号独立保存专业偏好、收藏、计划、笔记、AI 报告和加密后的 DeepSeek Key。

## 隐私与部署说明

网页版包含公开赛事浏览和登录后的个人空间。账号隔离收藏、计划、笔记、AI 报告与 Key；个人 DeepSeek Key 在服务端使用 `DATA_ENCRYPTION_KEY` 加密保存。网页不回显 Key，也不会把 Key 跟随 HTTP 重定向发往其他主机。AI 请求需要用户主动确认，不会加入每日自动采集。

发布到自己的服务器前，请先按 `.env.example` 设置独立来源、监听地址和数据加密密钥，为个人空间配置 HTTPS，并确认公网不能绕过代理直连私有服务。公开只读服务与个人服务应使用独立配置，不要把真实 `.env`、账号数据、备份、部署地址或 SSH 配置提交到仓库。`compose.yaml` 是项目部署样例，使用前应根据自己的域名、端口、数据卷和网络边界检查配置。

开发或测试时不会自动访问原开发者的服务器；测试用假响应，不代表真实 AI 账户、云数据库、注册流程或线上部署已验证。

## 本地开发与测试

使用 Node 22+；生产镜像固定 Node 24 的已校验摘要，不升级服务器全局 Node。

~~~bash
cd web
npm ci --ignore-scripts
npm run build
npm test
npm start
~~~

默认 localhost:18080，无密码时仍可查看公开赛事，登录和 AI 不可用。为本机设置私有配置时自行将环境变量传给进程；npm start 不自动读取 .env（Compose 会读取）。纯前端不使用外部 CDN、第三方分析脚本或外部字体。手机使用整页滚动，桌面双列卡片；所有来源与 AI 文本转义后显示。
