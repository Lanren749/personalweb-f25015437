# 课堂现场演示脚本

建议控制在 8 分钟功能演示，另留 2 分钟回答问题。先演示普通功能，再演示 Agent。

## 1. 业务问题（30 秒）

“计算机专业学生常常知道要参加比赛，却不知道哪些比赛适合自己、来源是否可靠、最后能形成什么简历成果。比赛雷达把发现、筛选、计划和作品产出放在一个流程里。”

## 2. 普通功能（2 分钟）

1. 打开发现页，确认页面只显示中国国内赛事。
2. 搜索“牛客”或筛选“近期赛程”。
3. 打开详情，展示官方链接、赛程状态和来源读取时间。
4. 收藏一项并加入参赛计划，填写个人职责和技术方案。

## 3. Agent 功能（4 分钟）

1. 在偏好中填写“计算机科学与技术”“人工智能、Java 后端”和自己的目标。
2. 进入“AI 找比赛”，解释有两个模式：联网搜索和只分析已有目录。
3. 先选“只分析已有国内比赛”说明它只调用一次模型，不扩大搜索范围。
4. 再演示联网模式的确认框，说明可能产生费用和发送范围。
5. 展示结果中的来源 ID、逐字证据、匹配理由和作品产出建议。

## 4. 安全说明（1 分钟）

“Key 不在浏览器前端，不进入 Git；公网只读入口不能登录。用户确认后才调用付费 AI，失败不自动重试。模型不能自造赛事链接，推荐必须通过来源和逐字证据校验。”

## 5. 可能提问的回答

- 是否覆盖全部比赛？不是，项目明确标注来源范围和保守筛选边界。
- AI 会不会胡编？模型输出被限制为来源 ID，并进行证据包含校验；仍要求用户打开官网核实。
- 为什么不自动报名？报名涉及资格、协议和个人决策，应用只辅助准备，不替用户提交。
- 手机能不能用？HarmonyOS App 可用；网页版手机公开入口可查看。登录、个人数据和 AI 需要 HTTPS，当前无域名阶段用电脑 SSH 安全通道演示，配置域名证书后即可开放手机网页个人空间。
- 为什么公网地址不能登录？18081 是特意隔离的 HTTP 只读入口；密码和 Key 不能通过明文 HTTP 传输。多用户注册登录已经实现，部署到 HTTPS 域名后即可使用。
- 每个用户的数据是否独立？账号使用独立 session；个人数据、AI 额度、报告和加密 Key 按 userId 存储，服务端测试覆盖两个账号互相不可见。
