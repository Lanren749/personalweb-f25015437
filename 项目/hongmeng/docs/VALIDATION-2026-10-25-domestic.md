# 国内来源与手机整页滚动 · 2026-10-25

## 行为变更

- 自动来源切换为牛客自办算法赛与中国大学生计算机设计大赛公告。腾讯广告算法大赛、华为云大赛、蓝桥杯继续作为手动官网入口。
- 牛客解析公开列表中内嵌的 HTML 转义 JSON，保留准确的开赛与结束时间；只接受已核实主办方、分类与自办赛事系列。国外转载、未知主办方和时间窗口外记录不进入列表。不将开赛时间冒充报名截止。
- Codeforces、AtCoder 不再自动请求。页面只投影国内条目，旧缓存、收藏标记、计划和笔记不删除。旧缓存首次迁移重置来源更新计时，使国内来源能够重新获取；原自动更新开关继续生效。
- 手机发现页、收藏页与计划页共用单个纵向 List；标题、搜索、筛选、状态与卡片一起滚动。移除手机端大统计卡与固定底部状态行。顶栏和底部导航保留。
- 点击底部列表入口回到列表顶部；同样适用于再次点击当前「发现」。桌面继续使用多栏结构。

- 仅覆盖上述两个自动来源和三个官网入口，尚非全国全部赛事聚合；4C 条目包括获奖/赛后公告，不表示正在报名。
