比赛雷达

基于 DeepSeek 的中国国内竞赛发现与简历经验规划 Agent

汇报人：宋佳威　|　学号：f25015437

面向计算机专业学生：找到适合自己的比赛，把过程沉淀为真实作品和可验证经历。
01 · Problem

学生真正需要的不只是搜索

信息分散

高校赛事、企业挑战赛和平台赛程分布在不同来源。

适配困难

同一场比赛是否适合自己的专业、方向和时间投入，需要判断。

经验难沉淀

报名、职责、技术方案和成果没有被组织成可复用的经历。

AI 有风险

赛事事实、截止时间和报名资格不能依赖模型记忆。

02 · Product

一个可真实使用的普通应用

  • 发现、搜索、近期筛选和国内来源说明
  • 详情、收藏、参赛计划、阶段和笔记
  • 自由填写专业、方向、目标和基础
  • HarmonyOS 手机/2in1 与桌面/手机网页
  • 服务器每日采集公开来源，个人数据独立保存
03 · Agent

自然语言目标驱动的研究流程

专业 / 方向 / 目标→生成检索词→搜索来源→国内过滤→结构化推荐→证据核验

用户选择“联网搜索 + AI 推荐”或“只分析已有国内比赛”，每次付费任务都先确认。

04 · Tools & Skill

Agent 不是黑盒聊天

业务工具

build_search_queries、search_competitions、filter_domestic_sources、verify_evidence、save_report

Skill

明确输入、工作流、输出格式、隐私边界、成本限制和失败策略。

证据约束

推荐只能引用输入来源 ID，证据必须逐字出现在来源标题或摘要中。

国内约束

HTTPS、国内域名和中文赛事线索检查；排除明显国外赛事。

05 · Safety

可控、可追溯、可解释

  • Key 只在服务器或设备安全存储，绝不提交 Git。
  • 笔记、收藏和参赛计划不会发送给 AI。
  • 固定官方 API 域名，限制请求次数、响应大小和每日额度。
  • 失败不自动付费重试，取消时明确提示已发请求可能计费。
  • AI 结果展示来源和核实提示，不自动报名、付款或承诺简历收益。
06 · Web & Account

从公开浏览到个人空间

公网 HTTP→赛事只读｜HTTPS / SSH→注册登录→个人数据 + AI Key

每个账号拥有独立偏好、收藏、计划、笔记、额度、报告和加密 Key。没有域名时用 SSH 隧道安全演示；配置可信 HTTPS 后即可从手机浏览器使用。

07 · Verification

代码和测试证明了什么

服务端测试

20 项测试全通过：账号隔离、CSRF、Host、只读公网、Key 加密、额度和失败保留。

Agent 测试

首轮必须产生标准 tool_calls，服务端执行搜索或目录分析，再用来源 ID 和逐字证据核验。

原生测试

HarmonyOS 的日期、筛选、来源解析、网络边界、AI 解析和存储回归测试保留。

诚实边界

不是全国赛事穷举，不自动报名，不保证获奖或简历加分，最终以主办方官网为准。

08 · Demo

八分钟功能演示

  1. 发现页筛选国内近期比赛，打开官方详情。
  2. 填写“计算机科学与技术 / AI、Java 后端 / 想形成真实项目”。
  3. 执行“只分析已有国内比赛”，展示一次模型调用。
  4. 执行联网搜索，展示工具调用、来源、逐字证据、理由和行动建议。
  5. 注册第二个账号，快速说明个人数据隔离；回到第一个账号加入参赛计划，填写真实职责。
